# Cloud-computing

This repository contains all assignments and lab work for the Cloud Computing course focused on AWS services and cloud architecture. The course progresses through fundamental AWS concepts and services, with programming assignments that build practical skills in cloud resource management and serverless application development.

## Project Structure

1. **Programming Assignment 1 - Create user/role/bucket/object programmatically**
   - Focus: AWS IAM and S3 fundamentals
   - Skills: Programmatic resource creation and AWS SDK usage

2. **Programming Assignment 2 - Use Lambda to count total object size**
   - Focus: AWS Lambda and S3 integration
   - Skills: Serverless computing and object manipulation

3. **Programming Assignment 3 - Use CDK to deploy the resources in Assignment 2**
   - Focus: Infrastructure as Code with AWS CDK
   - Skills: Automated deployment and resource management

4. **Programming Assignment 4 - Apply SNS/SQS and CloudWatch to Assignment 2**
   - Focus: Messaging services and monitoring
   - Skills: Asynchronous messaging patterns and observability

## Setup Instructions

1. Clone this repository:
   ```
   git clone https://github.com/yourusername/cloud-computing-course.git
   ```

2. Navigate to the specific assignment directory:
   ```
   cd cloud-computing-course/assignment-1
   ```

3. Follow the README instructions in each assignment directory for specific setup requirements.
